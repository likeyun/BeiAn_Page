# BeiAn_Page

一个纯静态个人技术博客模板，适合直接部署到 GitHub Pages。

## 当前结构

- `index.html`：博客首页与文章展示
- `ba_img/`：博客文章配图
- `.github/workflows/pages.yml`：GitHub Pages 自动部署

## 在线访问

https://likeyun.github.io/BeiAn_Page/

## 特点

- 纯 HTML / CSS / JavaScript
- 无 PHP、无数据库、无第三方框架
- 首页直接加载博客文章
- 支持移动端响应式
- 文章点击后可在当前页面阅读
- 保留 ICP 备案信息
